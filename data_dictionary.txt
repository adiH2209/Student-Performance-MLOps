STUDENT PERFORMANCE AND ACADEMIC-RISK CLASSIFICATION
DATA DICTIONARY AND VALIDATION RULES

SOURCE FIELDS
school: Student's school (categorical).
sex: Sex field as supplied by the source dataset (categorical).
age: Student age (numeric).
studytime: Weekly study-time category (numeric code).
failures: Number of previous class failures (numeric).
absences: Number of school absences (numeric).
G1: First-period grade (0-20).
G2: Second-period grade (0-20).
G3: Final grade (0-20).

DERIVED FIELDS
average_marks: (G1 + G2 + G3) / 3.
risk_level: Project-defined academic-risk category (High, Medium or Low).

VALIDATION
- Required numeric fields G1, G2, G3 and absences must be numeric.
- G1, G2 and G3 must be between 0 and 20 inclusive.
- Absences must be non-negative.
- Duplicate rows are removed.
- Rows with missing/non-numeric required values or invalid grade/absence values are rejected.
- Rejected rows are saved to data/errors/rejected_records.csv.

RISK RULES (evaluated in order)
High: G3 < 10 OR absences > 15.
Medium: if not High, G3 < 14 OR absences > 10.
Low: all remaining records.

IMPORTANT LIMITATION
The UCI Student Performance dataset does not contain verified dropout outcomes.
risk_level is derived from academic performance and absences. It is an
academic-risk indicator, not a confirmed dropout label.
